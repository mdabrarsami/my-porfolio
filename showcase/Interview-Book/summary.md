# The Senior Frontend Engineer's Interview Book (Interview-Book)

- One-line description: A Markdown book for senior and staff frontend interview prep, covering DSA, JavaScript, browser internals, networking, React and frontend system design.
- Type: personal
- Status: in progress (Parts 1 to 5 written, Part 6 started, Parts 7 to 13 planned)
- Live URL: none
- Repo: github.com/mdabrarsami/Interview-Book (private at time of writing)
- Dates: 2026-06-22 (single commit)
- Commits: 1

## What it does

A long-form interview prep book written for engineers with around ten years of experience targeting senior frontend roles. Every concept goes through the same layers: a precise definition, a plain-English explanation, the mechanics, senior-level trade-offs, a production example, what the interviewer is testing, code, complexity, common mistakes and follow-up questions. Every coding problem goes from brute force to optimal with edge cases.

## Highlights

- 35 chapter files, about 87,600 lines and 530,000 words of Markdown
- 688 DSA problems across 16 chapters (arrays through segment trees, Fenwick trees, KMP and Manacher), solved in JavaScript from brute force to optimal
- 100 JavaScript coding exercises and polyfills (compose, curry, debounce and similar)
- 173 output-prediction snippets covering hoisting, closures, `this`, event loop ordering, coercion and promises
- 276 JavaScript interview Q&A plus 85 more across browser internals, networking, React and system design
- React internals chapter on reconciliation, Fiber, concurrency and server rendering
- A fixed chapter template so every topic is taught the same way
