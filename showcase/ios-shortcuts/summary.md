# ios-shortcuts

- Name: ios-shortcuts (web app title: Shortcuts Builder)
- One-line description: Browser-based visual editor that builds, imports and exports iOS Shortcuts files, plus a code-generated photo archive shortcut.
- Type: Web app (React + TypeScript) and Node build script
- Status: Working prototype; two commits, not deployed
- Repo: github.com/mdabrarsami/ios-shortcuts
- Dates: 2026-06-29 (both commits, "init" and "init2")
- Commits: 2

## What it does

Shortcuts Builder lets you assemble an iOS Shortcut in the browser: pick from about 249 actions, drag them into a list (with nested If, Repeat and Menu blocks), set parameters and variables, and download a `.shortcut` binary plist that iOS accepts as an unsigned shortcut. It can also import an existing `.shortcut` file back into the editor. Separately, `build.js` uses shortcuts-js to generate an "Archive" shortcut that base64-encodes photos into a zip in iCloud Drive and deletes the originals, with a PIN-gated extract flow that decodes them back to the Camera Roll.

## Highlights

- Two-way conversion between a nested editor tree and Apple's flat `WFWorkflowActions` format (block start/end markers linked by `GroupingIdentifier`), with binary plist encode and decode in the browser.
- Action catalog generated by a script that reads the shortcuts-js package's JSDoc tags and `.d.ts` parameter types (124 actions), extended with hand-written definitions and overrides.
- Drag and drop with dnd-kit, typed parameter editors, variable chips, undo/redo in a Zustand store.
- Vitest suites for flatten, serialize, build/parse roundtrip, store and variables (42 tests).
- Documented Apple's signing limits: an in-app help dialog covers the install routes that work, and a GitHub Actions workflow for `shortcuts sign` is kept with a note on why it fails on hosted runners (it needs an iCloud login).

## Stack

React 18, TypeScript, Vite 5, Tailwind CSS 3, Zustand, dnd-kit, lucide-react, bplist-creator, bplist-parser, Vitest, Node.js, @joshfarrant/shortcuts-js, GitHub Actions.

## Distribution

No executables. Build outputs in the repo: `dist/Archive.shortcut` (5,220 bytes), `unsigned/Archive.shortcut` (7,791 bytes) and a `web/dist` bundle. The committed `web/dist` is older than the source (it lacks the current toolbar and help dialog), so rebuild before deploying. It is a static site, so it could go on Netlify or Vercel as a live demo.

## Worth showcasing?

Yes, as a side project. It is recent, the UI is clean, and the plist round-trip and catalog generation are good technical talking points. Weak spots: only two commits on one day, no deployed demo, and the Archive shortcut's "password" is a fixed PIN compared through base64, which should not be described as security. Deploy the builder and lead with it; mention the Archive shortcut only as the example it started from.
